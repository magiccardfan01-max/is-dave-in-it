# Is Dave In It?

A fun Next.js app that tells you whether **Dave Bautista** (Drax the Destroyer) is in any movie or TV show.

Inspired by a cool side-project idea spotted on X/Twitter.

## Features

- ⚡ Instant search across 50+ film & TV credits
- 🎯 Fuzzy matching + aliases (e.g. "GotG 3", "Dune 2")
- 🟢 Big **YES** / **NO** result with role details
- 🎬 Full clickable filmography grid
- 🌙 Dark, modern UI with Tailwind CSS
- 📱 Fully responsive

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Zero external APIs (static filmography data)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Ready for Vercel. One-click deploy.
